Features

Play, pause, next, and previous song controls

Dynamic playlist functionality

Real-time progress bar and duration tracking

Click-to-seek audio progress

Volume control slider

Auto-play next song feature

Responsive and modern UI design

Interactive playlist highlighting

Technologies Used

HTML5

CSS3

Functionalities

Users can play and pause songs with a single click.

Navigate between songs using Next and Previous buttons.

View song title, artist name, and cover image dynamically.

Track song progress with a real-time progress bar.

Adjust audio volume using the volume slider.

Select songs directly from the playlist.

Automatically plays the next song when the current track ends.
